# Public File Viewer

  A simple static webpage for viewing uploaded files via GitHub Pages.

  ## Setup

  1. Fork or clone this repo under your `Hadiy-77` account
  2. Enable GitHub Pages in repo settings (source: `main` branch, root)
  3. Visit: `https://hadiy-77.github.io/public-files/`

  ## Usage

  1. Upload files to `files/` directory in this repository
  2. View files via: `view.html?file=filename.ext`
  3. Or use the input field on `index.html`

  ## File Types Supported

  - **PDFs**: Embedded viewer
  - **Images** (PNG, JPG, GIF): Direct display
  - **Text/JSON**: Styled view
  - **HTML**: Iframe embedding
  - **Other**: Download link

  ## Direct Access

  All files accessible via raw URL:
  https://raw.githubusercontent.com/Hadiy-77/public-files/main/files/filename.ext
